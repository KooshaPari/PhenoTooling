# @anthropic-ai/elicitate-mcp

Native OS popup elicitation for autonomous agents — prebuilt MCP server binary.

## Install

```sh
npm install -g @anthropic-ai/elicitate-mcp
# or
bun add -g @anthropic-ai/elicitate-mcp
```

## Usage

```sh
elicitate-mcp          # MCP server (stdio)
elicitate --help       # CLI
```

## Supported Platforms

| Platform | Architecture |
|----------|-------------|
| macOS    | arm64 (Apple Silicon), x64 |
| Linux    | x64, arm64 |
| Windows  | x64 |
